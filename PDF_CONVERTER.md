# Конвертация маршрутного PDF

Для маршрутных листов партнёра используется детерминированная команда:

```bash
sudo apt install poppler-utils tesseract-ocr tesseract-ocr-rus
cd /path/to/courier-router
source .venv/bin/activate
courier-route pdf-to-xlsx "Развозка 23.09.2026 Толя.pdf"
```

По умолчанию рядом с PDF создаётся XLSX с тем же именем. Выходной файл можно
задать вторым аргументом:

```bash
courier-route pdf-to-xlsx input.pdf data/input/route.xlsx
```

XLSX создаётся без строки заголовков в формате, который принимает веб-интерфейс:

1. тип операции;
2. номер заказа;
3. телефон;
4. район;
5. адрес;
6. подъезд/этаж — пусто, если этого нет в PDF;
7. временное окно;
8. сумма и способ оплаты;
9. комментарий.

То же преобразование выполняется автоматически при загрузке PDF через веб-интерфейс;
отдельно конвертировать файл перед загрузкой не обязательно.
Команда `courier-route plan input.pdf --date 2026-09-23 --depart 17:00 --output data/output/route`
также принимает PDF напрямую.

Поворот страницы определяется на уменьшенной копии, затем выбранная ориентация
распознаётся в полном разрешении. Это позволяет обрабатывать листы, напечатанные
боком, в пределах общего лимита времени. Проверены одностраничные листы за
22.09.2026 (6 точек) и 23.09.2026 (4 точки), включая переносы адресов и окно
19:30–20:30 в колонке комментария.

Конвертер рассчитан на текущий печатный шаблон «Маршрутный лист». Он распознаёт
PDF через локальный Tesseract, не отправляя файл во внешние сервисы, и останавливается
с ошибкой, если не может уверенно разобрать строку.
