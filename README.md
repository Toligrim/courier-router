# Courier Router

Рабочая первая версия небольшого планировщика маршрута для одного водителя-курьера
по Санкт-Петербургу и Ленинградской области.

Вход: XLSX, CSV или маршрутный PDF партнёра. Поддерживаются два вида таблиц:

- Excel/CSV без заголовков, колонки A-H:
A тип операции, B номер заказа, C телефон, D район, E адрес,
F подъезд/этаж, G временное окно, H оплата.
- Печатный «Маршрутный лист» с названием, датой и шапкой
  `# / Тип / Заказ / Адрес / Район / Телефон / Сумма / Оплата / Время / Комментарий / Отметка`.
  Колонки определяются по заголовкам; номера заказов вида `#00503`, отдельная сумма,
  гарантийная бесплатная оплата и комментарии сохраняются. Проверяются нумерация строк
  и количество выездов, если они указаны в листе.

PDF этого печатного шаблона принимается через веб-интерфейс и `courier-route plan`
без предварительной конвертации. Для OCR нужны Poppler и Tesseract с русским языком;
ориентация повёрнутых страниц определяется автоматически.

В колонке A поддерживаются «Забор»/«Забрать», «Отвоз»/«Отвезти» и
«Доставка»/«Доставить», а также сокращения «Заб.», «Отв.», «Дост.».
Регистр, лишние пробелы и разделители не мешают распознаванию.
Пометка «Уточнить» до или после операции (например, «Уточнить Забор» или
«Доставка (уточнить)») сохраняется в комментарии точки. Комментарий из
необязательной колонки I также сохраняется. Неизвестные и неоднозначные типы
выдают ошибку с номером строки и колонкой A.

Выход:
- `itinerary.txt` — человекочитаемый порядок объезда с ETA;
- `route.json` — машиночитаемый результат;
- `route.png` — статическая карта с нумерованными точками и линией маршрута;
- `geocoding-report.json` — сведения о точности геокодирования.

## Архитектура MVP

Excel → deterministic parser → DaData → ORS Matrix → OR-Tools →
ORS Directions → Pillow renderer → TXT/JSON/PNG.

Затем ORS можно заменить на локальный OSRM одной настройкой `ROUTER=osrm`.

LLM намеренно не участвует в математической оптимизации. Его адаптеры предназначены
только для разбора/разрешения неоднозначных адресов и отключены по умолчанию.
Телефон и данные оплаты в LLM не отправляются.

Подробная установка: `INSTALL.md`.
Конвертация маршрутных PDF партнёра: `PDF_CONVERTER.md`.
Инструкция для автономного coding/deployment-агента: `AGENT_DEPLOYMENT_PROMPT.md`.
